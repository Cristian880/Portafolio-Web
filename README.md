# Portfolio Web

Portafolio profesional personal, construido para mostrar proyectos, experiencia y habilidades técnicas de forma dinámica.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Despliegue: Vercel

## Características

- Panel de administración privado para gestionar proyectos, experiencia y perfil sin tocar código
- Consumo de API REST propia ([portfolio-api](https://github.com/Cristian880/portfolio-api))
- Diseño responsive, optimizado para performance

## Desarrollo local

\`\`\`bash
pnpm install
pnpm dev
\`\`\`
